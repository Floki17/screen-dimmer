# Затемнитель экранов (Screen Dimmer)

Программа автоматически затемняет все дополнительные мониторы (кроме основного) в заданный временной интервал. Полезно для снижения яркости и отвлекающих факторов в ночное время, например, при работе с несколькими экранами.

## Как это работает

- Приложение создаёт чёрные окна во весь экран на всех мониторах, **кроме основного** (primary).
- Окна всегда находятся поверх других окон (`-topmost`).
- Затемнение активируется и деактивируется автоматически по расписанию.
- Проверка времени происходит каждую минуту.

## Установка

1. Убедитесь, что у вас установлен Python 3.6 или новее.
2. Установите необходимую библиотеку:
   ```bash
   pip install screeninfo

3. Скачайте скрипт screen_dimmer.py (или сохраните код из этого репозитория).
4. Отредактируйте переменные в начале скрипта:
     ```bash
   START_HOUR = 22
   START_MINUTE = 30   # 22:30
   END_HOUR = 6
   END_MINUTE = 15     # 06:15
